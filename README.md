# اتوپلازا تهران (Tehran Auto Plaza)

پایگاه جامع رصد، تحلیل، ساختار سازمانی و داده‌های اطلاعاتی مگاپروژه اتوپلازا تهران متعلق به هلدینگ کانون ایران نوین (نوین ونچرز).

## مشخصات کلیدی مجموعه
- **وسعت کل:** ۱۶۴,۰۰۰ متر مربع
- **فضای شوروم‌های اختصاصی:** ۸۲,۰۰۰ متر مربع (۹۰ شوروم نمایندگی رسمی برندها)
- **پارکینگ و پیست:** ۸۲,۰۰۰ متر مربع با ظرفیت ۳,۰۰۰ خودرو
- **فناوری:** سوپراپلیکیشن مجهز به ۱۹ دستیار هوش مصنوعی
- **مالکیت و بهره‌بردار:** کانون ایران نوین / نوین ونچرز
- **موقعیت:** تهران، کیلومتر ۱۱ بزرگراه شهید لشگری (جاده مخصوص کرج)، نبش خیابان ۳۰

## محتوای ریپازیتوری
- `index.html`: وب‌سایت تعاملی و پرتال جامع تحت GitHub Pages با هویت بصری اختصاصی اتوپلازا
- `data/`: فایل‌های خام JSON و Markdown استخراج‌شده از اینستاگرام، تلگرام، تحلیل ساختار سازمانی و تایم‌لاین کمپین‌ها
- `assets/`: تصاویر، لوگوها، پوسترها و مدیاهای رسمی اتوپلازا
