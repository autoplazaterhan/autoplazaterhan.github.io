# Agent Directives: Tehran Auto Plaza (autoplazaterhan.github.io)

This repository contains the interactive research observatory, media intelligence, and data portal for **Tehran Auto Plaza (اتوپلازا تهران)**.

## Core Rules & Visual Identity
- Always read `DESIGN.md` before making any visual, styling, or layout changes.
- Visual identity is strictly derived from the official site `https://autoplaza.ir/`:
  - Primary Font: `RaviFaNum` (`assets/fonts/RaviFaNum-*.woff2`) with Persian digits.
  - Core Palette: Automotive Black (`#000000` / `#0a0a0a`), Crisp White (`#ffffff` / `#f5f5f5`), AutoPlaza Orange (`#e85a2a` / `#d44a1c` / `#ff6b35`).
  - Strict VibeFarsi RTL standard: logical properties only (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`).
  - Strict Zero Em-Dash (`-`) rule in all copy.
  - Zero UI emojis in design and components (use crisp Lucide/SVG icons).
